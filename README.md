# 1,500+ — A Thank You

A cinematic, mobile-first milestone page for Muhammad Hasan celebrating 1,500+ LinkedIn connections.

## Experience
- Chrome-inspired dimensional typography and orbital lighting
- Canvas particles that gather into the 1,500+ milestone on reveal
- Original synthesized chime using the Web Audio API (no external sound asset)
- Replay and sound controls
- Responsive dark interface with reduced-motion accommodation

## Run locally
```bash
npm install
npm run dev
``

Open http://localhost:3000.

## Deploy
This is a Next.js app and can be deployed to Vercel. Connect the GitHub repository and use the default Next.js build settings.

## Notes
The LinkedIn button currently points to LinkedIn's main site. Replace its URL in `app/page.tsx` with your profile URL when you want a direct profile link.
